# JH Aces of Thunder swapper
For owners of Aces of Thunder / War Thunder only. Holds TOOLS, no War Thunder files: the tools read the user's own install and build the overlay mods on the user's PC.
* Aces_Cockpit_Builder/ - builds 'JH_PR_2.5 WT - Aces Cockpits and Optics' (run 'Build Cockpit Mod.bat').
* WT asset pack generator + GUI swap tool - to be added (thread 'Spec split build with local mesh generators').
The generated mod folders must never be uploaded.
